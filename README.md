# 🎮 Gaming Sales Performance Dashboard

## 📌 Project Overview
This repository contains a comprehensive **Power BI Dashboard** focused on analyzing global gaming sales. The goal of this project is to transform raw sales data into actionable business insights, helping stakeholders understand market trends, regional performance, top-performing platforms, and genre popularity over time.

---

## 📊 Dashboard Key Metrics & Insights
Based on the data modeling and analysis within the dashboard, here are the core performance metrics:

* **💰 Global Financial Impact:** The dataset analyzes a massive total of **$8.92 Billion** in global video game sales revenue.
* **🌍 Regional Revenue Breakdown:** * **North America (NA):** Leading global sales with **$4.39 Billion** (approx. 49.2% of the market share).
  * **Europe (EU):** Following with **$2.43 Billion**.
  * **Japan (JP):** Accounting for **$1.29 Billion**.
  * **Rest of the World:** Generating **$0.79 Billion**.
* **🎮 Platform Dominance:** The **PlayStation 2 (PS2)** stands out as the ultimate top-performing platform in terms of total sales revenue.
* **🏆 Top-Selling Title:** **Wii Sports** is identified as the highest-selling individual game title globally within the analyzed dataset.

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** For data modeling, DAX calculations, and dashboard creation.
* **Power Query:** For Data Cleaning, Transformation, and ETL processes.
* **DAX (Data Analysis Expressions):** Used for creating custom measures and calculated columns (e.g., Regional Sales Percentages, Total Revenue).
